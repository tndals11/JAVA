# 📌 Java 학습 정리

> 자바(Java)의 기초 문법부터 객체지향 프로그래밍(OOP), 예외 처리, 컬렉션 프레임워크,  
> 내부 클래스, 람다식, 스트림까지 학습하며 정리한 내용을 담은 저장소입니다.


## ✍️ 학습 내용 요약

### 🔹 1. 자바 기초 문법
- **변수와 자료형**: 기본형(정수, 실수, 문자, 논리형)과 참조형의 차이 이해  
- **연산자**: 산술, 비교, 논리, 대입, 증감, 조건 연산자 등  
- **문자열 (String)**: 문자열 연결, `StringBuilder`, 주요 메서드 (`length()`, `substring()`, `indexOf()`, `equals()` 등)

---

### 🔹 2. 제어문
- **조건문**: `if`, `else`, `switch` 문을 이용한 분기 처리  
- **반복문**: `for`, `while`, `do-while`  
- **제어 키워드**: `break`, `continue`, `return` 사용법

---

### 🔹 3. 객체지향 프로그래밍 (OOP)

> 자바는 객체지향 언어로, 다음의 네 가지 주요 특징을 중심으로 구성됩니다.

#### 🧱 클래스와 객체
- 클래스는 객체를 생성하기 위한 설계도이며, 객체는 클래스의 인스턴스입니다.  
- 필드(속성)와 메서드(동작)를 통해 상태와 행동을 표현합니다.

#### 🔧 생성자, 메서드, 접근 제어자
- 생성자는 객체 생성 시 호출되며 오버로딩이 가능합니다.  
- 메서드는 특정 작업을 수행하는 코드 블록입니다.  
- 접근 제어자: `public`, `private`, `protected`, (default)로 외부 접근을 제어합니다.

#### 🧬 상속
- `extends` 키워드를 사용하여 부모 클래스의 기능을 자식 클래스에 상속  
- 코드 재사용성 및 유지보수성 향상

#### 🧱 추상 클래스와 인터페이스
- **추상 클래스**: `abstract` 키워드를 사용하여 공통 기능 정의 + 일부 구현  
- **인터페이스**: 구현이 없는 메서드로 구성된 설계도이며, 다중 구현 가능 (`implements`)  
- 자바 8 이후에는 `default`, `static` 메서드도 정의 가능

#### 🔄 오버라이딩과 오버로딩
- **오버로딩 (Overloading)**: 같은 이름의 메서드를 매개변수 형태를 달리하여 여러 개 정의  
- **오버라이딩 (Overriding)**: 부모 클래스의 메서드를 자식 클래스에서 재정의

---

### 🔹 4. 예외 처리
- `try-catch-finally`: 예외 발생 시 처리 흐름 관리  
- `throw` / `throws`: 예외를 직접 발생시키거나 호출자에게 위임  
- 사용자 정의 예외: `Exception` 또는 `RuntimeException`을 상속하여 직접 구현

---

### 🔹 5. 컬렉션 프레임워크
- **List**: 순서가 있는 데이터 저장 (`ArrayList`, `LinkedList`)  
- **Set**: 중복을 허용하지 않고 순서 없음 (`HashSet`, `TreeSet`)  
- **Map**: 키-값 쌍 저장 (`HashMap`, `TreeMap`)  
- **제네릭(Generic)**: 클래스나 메서드에서 사용할 데이터 타입을 일반화

---

### 🔹 6. 내부 클래스 (Inner Class)
- 클래스 내부에 선언된 또 다른 클래스  
- 종류: 인스턴스 내부 클래스, 정적(static) 내부 클래스, 지역 클래스, 익명 클래스  
- 외부 클래스의 멤버에 접근 가능

---

### 🔹 7. 람다식 (Lambda)
- 익명 함수 형태로 표현된 간결한 문법  
- 함수형 인터페이스(`@FunctionalInterface`) 구현 시 사용  
- 코드 간결성과 가독성 향상

---

### 🔹 8. 스트림 (Stream)
- 자바 8에서 도입된 데이터 처리 방식  
- 컬렉션의 데이터를 필터링, 매핑, 정렬 등으로 효율적으로 처리 가능  
- 선언형 스타일과 병렬 처리 지원

---
