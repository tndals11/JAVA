# 📘 JAVA 학습 

## ✍️ 학습 내용 
🔹 1. 자바 기초 문법
변수와 자료형: 기본형(정수, 실수, 문자, 논리형)과 참조형의 차이 이해

연산자: 산술, 비교, 논리, 대입, 증감, 조건 연산자 등

문자열(String): 문자열 연결, StringBuilder, 주요 메서드 (length(), substring(), indexOf(), equals() 등)

🔹 2. 제어문
조건문: if, else, switch 문을 이용한 분기 처리

반복문: for, while, do-while 반복문

제어 키워드: break, continue, return 사용법

🔹 3. 객체지향 프로그래밍 (OOP)
자바는 객체지향 언어로, 다음 네 가지 주요 특징을 기반으로 구성됩니다.

🧱 클래스와 객체
클래스는 객체를 생성하기 위한 설계도이며, 객체는 클래스의 인스턴스

필드(속성)와 메서드(동작)를 통해 상태와 행동 표현

🔧 생성자, 메서드, 접근 제어자
생성자는 객체 생성 시 호출되며, 오버로딩 가능

메서드는 특정 작업을 수행하는 코드 블록으로, void, 반환형, 매개변수 사용

접근 제어자: public, private, protected, (default) 로 외부 접근 제한

🧬 상속
extends 키워드로 부모 클래스의 기능을 자식 클래스가 물려받음

코드 재사용성과 유지보수성 향상

🧱 추상 클래스와 인터페이스
추상 클래스: abstract 키워드 사용, 공통 기능 정의 + 일부 메서드 구현

인터페이스: 완전한 설계도, 다중 구현 가능 (implements)

자바 8 이후 인터페이스에 default, static 메서드도 가능

🔄 오버라이딩과 오버로딩
오버로딩: 같은 이름의 메서드를 매개변수 다르게 정의 (컴파일 시 결정)

오버라이딩: 부모 클래스의 메서드를 자식 클래스에서 재정의 (런타임 시 결정)

🔹 4. 예외 처리
try-catch-finally: 예외 발생 시 처리 흐름 관리

throw / throws: 예외를 직접 발생시키거나 위임

사용자 정의 예외: Exception 혹은 RuntimeException을 상속하여 직접 예외 클래스 구현

🔹 5. 컬렉션 프레임워크
List: 순서가 있는 데이터 저장 (ArrayList, LinkedList)

Set: 중복 불허, 순서 없음 (HashSet, TreeSet)

Map: 키-값 쌍 저장 (HashMap, TreeMap)

제네릭(Generic): 클래스나 메서드에서 사용할 데이터 타입을 매개변수로 일반화

🔹 6. 내부 클래스 (Inner Class)
클래스 안에 선언된 클래스

종류: 인스턴스 내부 클래스, 정적(static) 내부 클래스, 지역 클래스, 익명 클래스

외부 클래스의 멤버에 접근 가능 (특히 인스턴스 내부 클래스는 외부 인스턴스 참조 가능)

🔹 7. 람다식 (Lambda)
익명 함수 형태의 표현식, 간결한 코드 작성 가능

함수형 인터페이스(@FunctionalInterface)를 구현하는 데 사용

🔹 8. 스트림 (Stream)
자바 8 도입, 컬렉션 기반 데이터 처리 방식

병렬 처리, 가독성 높은 코드 작성 가능
